## Scope

Whole one-page portfolio (`src/pages/index.astro` and its components: hero, client strip, work, about, contact, footer, plus the 404 page). Mode: Persuade — two audiences (small-business owners deciding to commission work, employers/recruiters deciding to interview) both need to act.

## Direction contract

THESIS: The portfolio is a component datasheet for a person, not a hero-glow SaaS landing page — every claim reads as a measured spec, not a pitch. Refuses the near-black canvas / single neon accent / glass-card / gradient-hero arrangement (the incumbent, and the category default this whole genre converges on).

OWN-WORLD: Bone-white paper ground (#F7F6F2), graphite ink (#1A1A18), one cobalt accent (#1E4FD8) reserved for status stamps, active states, and rules — never scattered as decoration. Big Shoulders Display (industrial, tall, stamped-plate character) for display/title-block headlines, Work Sans for body, JetBrains Mono for part numbers, data, and labels (kept from the incumbent — it already reads right here). Hairline (1px) rules building a title-block grid; ruled tables carrying real tabular data; a corner "REV" stamp motif; footnote-style numbered annotations. Raised from the roll's challengers: kit-numeral confidence (bold, oversized figures for status/counts, donated from the football-kit crest challenger), plate-numbered figures (every diagram/mark numbered like a measured plate, donated from the curved-crease-shell challenger), and a signed/dated maker's mark per project entry (donated from the embroidery-sampler challenger, kept deliberately spare so it reads as authorship/accountability, never as a "still learning" narrative — that reading is out of scope per PRODUCT.md's positioning).

STORY: The visitor understands this is real, shipped, in-daily-use software, documented with the same precision as an engineering part, not pitched like a startup. They believe the person behind it is rigorous and already proven — not a student with class projects. They act by reading the project spec table, seeing the "IN DAILY USE" / "IN USE" stamps as real status, and reaching the contact block through the datasheet's own vocabulary (an "ordering information" style panel), not a generic CTA button.

FIRST VIEWPORT: A full-bleed title-block strip spans the top like a datasheet header: small tracked mono caps "PORTFOLIO · REV 2026" at the left, the name at the right, one hairline rule beneath. Below it, a two-column masthead — left ~60% carries the pitch as a large Big Shoulders Display headline set like a datasheet's principal description paragraph, with a short cobalt rule underscoring the accent phrase; right ~40% is a compact boxed mono "quick specs" table (role, location, availability, languages), hairline-bordered exactly like a datasheet's ordering-information block. The primary action ("Get in touch") renders as a stamped mark in cobalt, sitting at the base of the masthead's left column, not a pill button.

FORM: Engineering datasheet / component spec sheet. Candidate 3 of 7 on the ranked, resonance-ordered list drawn from the audience's real-world visual systems (thermal label sheet, till receipt, datasheet, PCB schematic, inventory ledger, shop signage, till keypad) — assigned by the roll (seed key c866e809), confirmed by the user over the Spec Sheet / Label Sheet / Instrument Panel / category-standard round.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
